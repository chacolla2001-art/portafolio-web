# Portafolio web

Página personal de Pedro Chacolla, en español e inglés: https://chacolla2001-art.github.io/portafolio-web/

Hecha a mano con HTML, CSS y JavaScript, sin frameworks, librerías ni fuentes externas.

- `construir.mjs` genera `index.html` (español) y `en.html` (inglés) desde una sola plantilla: `node construir.mjs`.
- `estilos.css` contiene el diseño: fondo claro, un solo color de acento y animaciones mínimas, que se desactivan si el sistema pide menos movimiento.
- `app.js` hace que las secciones aparezcan suavemente al desplazarse. Sin JavaScript la página se ve completa.
